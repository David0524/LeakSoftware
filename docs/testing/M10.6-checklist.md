# M10.6 checklist: maintenance (regular pool cleaning)

Playwright covers the done-when (`apps/web/e2e/maintenance.spec.ts`) and pgTAP covers the
rules (`supabase/tests/200_maintenance.test.sql`). These steps need real phones and a few days.

## Setup (owner, once)
1. Apply the database migrations: `pnpm db:deploy` (and `-- --seed` for the demo plans).
2. Settings › Scheduling: check the maintenance visit length (30 minutes) and how many weeks
   ahead visits are scheduled (4).

## Check
1. **Add a plan:** a customer's page → Add Maintenance Plan → weekly, a tech, a price → Add
   Plan. The plan line reads "Every Tuesday · any time · 30 min · $95.00 a visit" and lists the
   next visits.
2. **Schedule:** the visits are on that tech's route each week, marked Maintenance, after
   their other jobs. Plan Route puts them in the best order.
3. **Phone:** the tech sees the visit on Today and in the phone app; the checklist is the
   service list (Done, Needs Attention, Skipped); Mark Done finishes it.
4. **Change the plan:** every 2 weeks, or a set time: upcoming visits move; a visit already
   started stays.
5. **Pause, Resume, End Plan:** upcoming visits leave and come back; finished ones stay.
6. **Next morning:** visits keep reaching four weeks ahead (the daily cron).
